# «Лапидус. Ни капли» — веб-версия и Telegram

Что в архиве `lapidus_web.zip` (пять файлов, без папок): `index.html`, `game.js`, `game.data`, `love.js`, `love.wasm`.
Это вся игра. Ей нужен только веб-сервер с HTTPS — GitHub Pages подходит и бесплатен.

## 1. Выложить на GitHub Pages (с iPhone или компьютера)

1. Откройте https://github.com и войдите в аккаунт (если нет — «Sign up», это бесплатно).
2. Справа вверху «+» → «New repository».
3. Repository name: `lapidus-web`. Оставьте Public. Поставьте галочку «Add a README file». Нажмите «Create repository».
4. На странице репозитория нажмите «Add file» → «Upload files».
5. Выберите пять файлов из архива (на iPhone: «choose your files» → «Обзор» → папка, куда распакован архив; можно выбрать все пять сразу).
   Файл `game.data` весит около 5 МБ, `love.wasm` — около 5 МБ; загрузка займёт минуту.
6. Внизу нажмите зелёную «Commit changes».
7. Откройте вкладку «Settings» репозитория (шестерёнка) → в левом меню «Pages».
8. В разделе «Build and deployment»: Source — «Deploy from a branch»; Branch — `main`, папка `/ (root)`; нажмите «Save».
9. Через 1–3 минуты обновите страницу Pages: появится строка «Your site is live at https://ВАШ_ЛОГИН.github.io/lapidus-web/».
   Откройте этот адрес — игра загрузится (первый раз до 10–15 секунд).

Обновление игры: снова «Add file» → «Upload files» с теми же именами файлов — новые версии заменят старые.
Старую версию браузер может держать в кэше: если после обновления видите прежнюю — откройте адрес с добавкой `?v=2`.

## 2. Подключить как Telegram Mini App

1. В Telegram откройте @BotFather → `/newbot`. Придумайте имя (например, «Лапидус») и username, заканчивающийся на `bot` (например, `lapidus_ni_kapli_bot`).
2. `/mybots` → выберите бота → «Bot Settings» → «Configure Mini App» → «Enable Mini App».
3. Вставьте адрес игры: `https://ВАШ_ЛОГИН.github.io/lapidus-web/`.
4. Там же по желанию: «Menu Button» → «Configure menu button» → тот же адрес и подпись «Играть».
5. Откройте чат с ботом — внизу появится кнопка «Играть». Игра открывается внутри Telegram на весь экран.
   Внутри Telegram страница сама просит полноэкранный режим и отключает вертикальные свайпы.
6. Ссылка для друзей: `https://t.me/ВАШ_БОТ` (кнопка «Играть» в чате).

Токен бота никуда вводить не нужно.

## 3. Что важно знать

- Телефон: игра только в альбомной ориентации; в портретной показывается просьба повернуть телефон.
  Первое касание в обычном браузере переводит в полноэкранный режим (в Safari на iPhone полный экран недоступен — просто играйте в окне).
- Прогресс сохраняется в браузере (IndexedDB) отдельно на каждом устройстве и в каждом браузере; Telegram на телефоне — тоже отдельное хранилище.
  Очистка данных сайта сотрёт прогресс.
- Звука в игре пока нет (§9 — позже), так что ограничение режима совместимости love.js на звук пока не мешает.
- Работает в Chrome, Firefox, Safari и внутри Telegram на iOS/Android. Клавиатура, мышь и касания — как в настольной версии.
