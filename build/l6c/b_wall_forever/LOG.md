# Направление B «стена навсегда, новая геометрия» — журнал кандидатов

Решения, кадры и порядок ходов здесь не пишутся. Метрики — из `luajit build/l6b/check.lua` (или `q.lua`, та же формула).
Инструменты папки: `q.lua` (строка метрик для файлов), `quick.lua` (метрики функцией), `ptraps.lua` (классы ходов вдоль
кратчайшего пути — только вывод инструмента), `show.lua` (кадры для себя), `tune.lua` (локальная доводка ядра: клетки «?»
и заранее выбранные старты), `gen.py` (ASCII-карта → файл уровня), `vis.lua` (честные видимые проигрыши), `mycheck.lua`
(check.lua + счётчик «живых, помеченных видимыми»).
