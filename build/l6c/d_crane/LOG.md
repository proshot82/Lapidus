# Направление D «Он сам себе кран» — журнал кандидатов (кв. 6 «Намертво»)

Решения, кадры и порядок ходов здесь не пишутся. Метрики — `luajit build/l6c/d_crane/q.lua <файл>` (та же формула,
что build/l6b/check.lua; ворота считает gates.lua). Инструменты папки: q.lua (строка метрик и провалы), gates.lua,
x.lua (конфигурации деталей: живые/мёртвые), hid.lua (где скрытые тупики), from.lua / play.lua (проверка линий —
только вывод инструмента), vischeck.lua (честность visibleLoss), mk.py / batch.py (ASCII → файл уровня, пачки).
Видимые проигрыши: vis0.lua (черновой: деталь на стене/закреплённом), visB.lua (только ниппель), visK.lua (семейство K).

## Этап 1 — механика крана (прототипы-песочницы, не уровни)
| кандидат | замысел | метрики | провалы |
|---|---|---|---|
| sb1, t1 | песочница: перехват (подбросить ниппель ногами и поймать головой) — работает | — | — |
| p2–p5, p6–p8 | две приёмные резьбы в потолке / две трубы над коридором | 3–9 ходов, скрытых 0 % | всё: детали на Лапидусе хрупкие, выбор конца вынужден стартом |
| p9, p10 | люк под колонкой (муфта падает в гнездо стояка) | нерешаемы | — |
| t2, t3 | перехват + муфта в трубе над кольцом 2×2 | 8–9 ходов, скрытых 0 % | кольцо 2×2 разворачивает Лапидуса — любая ошибка исправима |
| u1, u2 | две мелкие шахты под колонкой и стояком, U-финал | u1: 18 ходов, скрытых 0 % при честном vis, обезьяна 11,5 % | запасная комната 2×2 делает ошибку концом исправимой |
| v1–v8, w1–w6 | два яруса: муфту вверх по шахте к стояку, ниппель ногами, голова следом («α») | 8–13 ходов, скрытых 0 %; при Lmax 6 лазейка — прямое подключение | старт задаёт концы, ошибок нет |
| x1–x5, L1 | муфта падает в гнездо в полу коридора | 3–8 ходов, обезьяна ~100 % | тривиальны |
| k1, k5–k12 | «колонна с ловушкой стояка»: ниппель ногами вверх, обойти кольцом, муфту столкнуть в колонну, войти головой | k7: 16 ходов, скрытых 13 %, обезьяна 3,1 %, наобум 0,73 %, прогулка 5, выигрышных 1 | скрытые, обезьяна, глубина: ошибка «поднять головой» исправима разворотом, единственная ловушка — муфта при неверной ориентации |
| c1, c2 | гребёнка: боковые гнёзда колонки и стояка на стене шахты, стопка | c2: прямое подключение без деталей (2 выигрышных) | лазейка |

Вывод этапа 1: груз на Лапидусе хрупок — почти любой лишний ход роняет его (видимый проигрыш), поэтому выбор конца
задан стартом; а там, где выбор есть (кольцо, Т-развилка), та же развилка исправляет ошибку после закрепления.
Нужна структура, где закрепление само уничтожает ресурс разворота.
