## Почему не проходят обезьяна и «наобум»
Без подвижных деталей необратимо только падение; на 10×7 помещается одно необратимое падение, значит, одно решение
«каким концом вперёд», и обезьяна выигрывает, когда случайно развернулась до спуска. Поиск для оценки (уровень строился
руками): на 10×7 из 26,6 тыс. годных раскладок при скрытых ≥ 40 % обезьяна не ниже 4,5 %, до 0,2 % — только при скрытых
≤ 16 %; на 10×8 при скрытых ≥ 40 % обезьяна не ниже 2,7 %. Ни одна из 74 замен одной клетки k2 не улучшает.
